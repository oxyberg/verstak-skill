# Навык «Верстак»

«Верстак» — skill для pixel-perfect вёрстки экранов и компонентов по макетам Figma в Codex, OpenCode и Claude Code.

Исходники находятся в [`verstak/`](verstak/). Все платформы используют один `SKILL.md`, поэтому инструкции не дублируются и не расходятся между версиями.

Скилл выбирает объём чтения и проверки по масштабу задачи: локальная правка, компонент или новый экран. Он повторно использует проверенные данные, устраняет причины расхождений группами и завершает визуальную проверку, когда не осталось конкретных дефектов. Для сложных сравнений доступен необязательный [инструмент overlay/diff](verstak/references/visual-check.md).

Проверка инструмента: `python3 -m unittest discover -s tests` (нужен Pillow). [Протокол сравнения качества, времени и токенов](tests/benchmark.md) предназначен для сопровождающих скилла и не загружается при обычной вёрстке. Ускорение требует замеров на реальных задачах; наличие оптимизаций само по себе не подтверждает процент экономии.

## Установка в OpenCode

Глобально:

```sh
./scripts/install-opencode.sh --global
```

В конкретный проект:

```sh
./scripts/install-opencode.sh --project /path/to/project
```

Проверить обнаружение:

```sh
cd /path/to/project
opencode debug skill
```

Папку `verstak` также можно скопировать вручную:

- в проект: `.opencode/skills/verstak`;
- глобально: `~/.config/opencode/skills/verstak`.

После обнаружения skill доступен как `/verstak` и может выбираться агентом автоматически по `description`.
Навык выбирается для вёрстки по Figma, в том числе по фразам «сверстай по Figma» и «сверстай экран по макету», а также по явному обращению «Верстак». Slash-команда остаётся `/verstak`, поскольку идентификаторы skills используют латиницу.

## Установка в Claude Code

Глобально для пользователя:

```sh
./scripts/install-claude.sh --global
```

В конкретный проект:

```sh
./scripts/install-claude.sh --project /path/to/project
```

Проверить установку можно командами `/skills` и `/verstak` внутри Claude Code. Claude также может выбирать skill автоматически по `description`, включая русские триггеры.

## Установка в Codex

Установите папку `verstak` как обычный Codex skill. Файл `verstak/agents/openai.yaml` содержит UI-метаданные Codex и безопасно игнорируется OpenCode.
